# GTA 6 Deutsch

Unofficial German-language fan guides for GTA 6 (released November 19, 2026) — a static single-page site built for GitHub Pages.

**Live site:** https://gta6deutsch.github.io

## What it is

An original, German-language fan site: 5 calculators, a vehicle comparison table, 6 guides, FAQ, About and Disclaimer. Pure HTML5, CSS3 and vanilla JavaScript — no frameworks, no build step, no backend. All numbers are labelled community estimates / in-game approximations, never official Rockstar data.

## Calculators (all client-side)

1. **Verdienst-Rechner im Spiel** — earnings by activity, hours and weeks, minus costs.
2. **Beute-Aufteiler für Heists** — leader share first, remainder split evenly.
3. **Fahrzeug-Vergleich** — two vehicles compared on speed, acceleration, handling and price.
4. **Missions-Checkliste** — 10 story sections with progress and remaining time.
5. **Fortschritts-Tracker** — story, side missions, collectibles and money into one overall percentage.

Also included: a 6-vehicle comparison table (community estimates), six German guides, FAQ, About and Disclaimer.

## Disclaimer

Unofficial fan guide — not affiliated with Rockstar Games. No download links, no Rockstar artwork or assets, no claim of affiliation.

## Deploy to GitHub Pages

1. Create a public repository named **gta6deutsch** under the GitHub organization **gta6deutsch**.
2. Upload all files from this folder to the repository root.
3. In the repository: **Settings → Pages → Build and deployment → Deploy from a branch → branch `main`, folder `/ (root)` → Save.**
4. The site goes live at **https://gta6deutsch.github.io** within a few minutes.
